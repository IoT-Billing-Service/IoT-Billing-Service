# Meter Simulator CLI

A Node.js CLI tool that mimics an ESP32 sending usage data to the IoT-Billing-Service smart contracts for local development and testing.

> 📄 Full documentation — installation, usage, commands, and examples — lives in [`docs/developers/smart-contracts.md`](../../docs/developers/smart-contracts.md). Generated Soroban TypeScript bindings are documented in [`docs/developers/typescript-bindings.md`](../../docs/developers/typescript-bindings.md) (consolidated in [#308](https://github.com/IoT-Billing-Service/IoT-Billing-Service/issues/308)).

See the [documentation index](../../DOCS.md) for all contributor, developer, and operator guides.
